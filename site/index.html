Before you settle in

A few little answers.

Will it work with my desktop?

Velvet Scroll works through Linux evdev and uinput, below the desktop. It is designed for KDE Plasma, GNOME and other desktops on Wayland or X11. Linux device access and an active-seat permission setup are required. Hardware and desktop testing is ongoing; see the compatibility notes.

Does it change my cursor speed?

Only wheel values are accelerated. The virtual mouse preserves the physical mouse's identity, calibration, pointer deltas and event timing so your usual pointer settings remain in effect.

Is this like an unlocked scroll wheel?

It brings some of that convenience to a regular wheel: a quick flick travels farther, and optional coasting adds a short glide. It is a software approximation, not a physical free-spinning wheel. Animation and smoothness still depend on the application.

Can I switch it off quickly?

Yes. Use the tray toggle or bind velvet-scroll toggle to a desktop keyboard shortcut. You can also disable it in the settings window. No mouse is selected automatically.

Do I need to run it as root?

No. The daemon and GUI run as your desktop user. Installing the package and setting up device permissions requires administrator access once. Follow the installation guide, then launch Velvet Scroll without sudo.

How can I help?

Try it with your setup, report a bug, or contribute a change. Include your distro, desktop/session type and mouse model. Redact device serial numbers and personal paths from any diagnostic output.
